### พิกัดภายใน canvas

* แกนนอน: `X0(t) = LABELW() + (t - S.offset) * S.zoom` — `T0(x)` คือตัวกลับ
* แกนตั้งของบรรทัด 5 เส้น: `py(pos) = STAFF_TOP + (8 - pos) * HG` โดย `HG = 4`
  (`pos` 0 = เส้นล่างสุด, 8 = เส้นบนสุด)
* `STAFF_TOP = HEAD + 46`
* แถวเสียงกลองเริ่มหลังหัว + แถบบรรทัด แต่ละแถวสูง `--rowh`

### บริเวณที่รับการแตะ (ดู `cv.addEventListener("pointerdown")`)

| บริเวณ | ผล |
|---|---|
| `p.head` (ทั้งแถบ 0–54) | **แตะ = ตั้งจุดเล่น** (กดเล่นจะเริ่มจากตรงนั้น) · **ลาก = ตั้งช่วงวนซ้ำ** · ✕ ท้ายช่วง = ยกเลิก |
| `p.staff` | ไม่ทำอะไร (แถบบรรทัด 5 เส้น) |
| แถวเสียง | วาง/ลบ/เลือก/ปรับน้ำหนัก ตามเครื่องมือที่เลือก |

รับทีละจุดสัมผัสเท่านั้น (`activePid`) เพราะฝ่ามือแตะจอตอนใช้ปากกาเคยทำให้
เกิดโน้ตผิดและมีเสียงกลองดังขึ้นมาเอง

## Transport bar (`#tp`)

`position:fixed` ติดขอบล่างเสมอ **แม้อยู่ในโหมด `body.locked`**
สูงได้ถึง `52dvh` และเลื่อนในตัวเองได้ · ย่อได้ด้วย `#tpToggle` (`.min`)

**ย่อแล้ว (`#tp.min`)** เหลือแถวเดียว: `#play` `#stopb` `#home` `#clock` (`#kLamp`) `#tpMix` (แถบเสียงเพลง/กลอง สำเนาของ `#vol` `#dvol`
ซ่อนบนมือถือ — มือถือใช้หมวด "เสียง" `.np-sec[data-cat="mix"]` ในแผงเขียนโน้ตแทน) สูงราว 58px
(รุ่น 11 ย่อแล้วไม่มีอะไรยุบเพราะซ่อนแค่ `#rowMore` ที่ไม่มีแล้ว) · จำสถานะใน `localStorage["klongpro.tpmin"]`

## แผงเขียนโน้ตลอย (`#npal`) + ปุ่มกลม (`#npPin`) — ข้อ 35 ในโค้ด

ขึ้นเมื่อแถบล่างย่อเท่านั้น · หมวด: ค่าโน้ต (`#vals` + ปุ่มประจุดผูกกับ `#dotted`) ·
น้ำหนัก (`#dynSeg`) · ลูกเล่น (`#ornSeg2` + `#tremSeg`) · การวาง (`#lineSeg` ในแผงตั้งค่า)
**ปุ่มในแผงเป็นสำเนา** (`.np-m[data-src]`) แตะแล้วไป `.click()` ปุ่มเดิมตามลำดับ และสร้างสำเนาใหม่
เมื่อปุ่มเดิมเปลี่ยน (MutationObserver) — แก้ตรรกะของปุ่มเดิมได้ตามปกติ แผงตามเอง
ลากหัวแผงย้ายได้ทั้งจอ · ซ่อนเองตาม `#npTime` แล้วเหลือ `#npPin` ตรงมุมเดิม (โชว์ค่าโน้ตที่เลือกอยู่)
แตะปุ่มกลม = เรียกแผง ลาก = ย้าย · ตำแหน่ง/หมวด/เวลา เก็บใน `localStorage["klongpro.npal"]`
**แถบห้องท้ายแผง** (`.np-bar` ติด sticky อยู่ล่างสุดทุกหมวด แม้เปิดทุกหมวดจนแผงเลื่อน): ปุ่ม `[data-for]`
ไป `.click()` `#barCopy` / `#barPaste` / `#barDup` ในแถบล่าง (ซ่อนอยู่ตอนย่อแต่กดได้) ·
`#npBarInfo` บอกห้องที่หัวอ่านอยู่ (`S.pos` ตามที่ปุ่มเดิมใช้) กับ `S.clip.from` แล้วโชว์ผลจาก `#status` 2.6 วิ

**บนมือถือ** (`html[data-kphone]`) แผงเกาะขอบจอ (`#npal.docked`): แนวตั้งอยู่ใต้กริดเหนือแถบล่าง หมวดละแถวเดียวสูง 64px
แนวนอนเป็นคอลัมน์ขวา (หมวดเป็นแถบตั้งซ้าย ปุ่มสองคอลัมน์) และ `#tp.min` ย้ายขึ้นไปอยู่บนแถบบน · ไม่มีหัวลาก ไม่ซ่อนเอง
แถบห้องเป็นหมวดที่ห้า "ห้อง" (`.np-tbar`) แทนแถบท้ายแผง · แถบบนเหลือ ↶ · `#tool` · `#kTbMore` (⋯ เปิดแถวสอง: นำเข้า ส่งออก ตั้งค่า โหมด)
· `#status` เป็นป้ายลอย (`.k-show`) · ดูข้อ 0.8 ของ SKILL.md

## หัวกริดแถบเดียว: แตะ = จุดเล่น · ลาก = วนซ้ำ — ข้อ 36 ในโค้ด

หัวกริดสูง 54px (`--head`, `HEAD = RULER_Y + RULER_H`): 0–26 เลขห้อง อัตราจังหวะ ความเร็ว · **26–54 ไม้บรรทัด**
ทั้งแถบรับท่าเดียวกัน (นิ้ว/ปากกา ทุกเครื่องมือ): **แตะ = ตั้งจุดเล่น** (`tapPlayAt` · เล่นอยู่ก็เล่นต่อจากตรงนั้น)
**ลากคลุม = ตั้งช่วงวนซ้ำ** · ลากขอบ = ปรับ · **✕ ท้ายช่วง** (`loopChip`) = ยกเลิก · แตะนอกช่วง = เลิกวนซ้ำแล้วตั้งจุดเล่น
ขีดยาว = ต้นห้อง · กลาง = จังหวะ (มีเลข) · สั้น = ช่องย่อยตามค่าโน้ต (หยาบสุดเขบ็ต 2 ชั้น) · ค้างนิ้วใกล้ขอบจอ = เลื่อนกริดต่อ
(เดิมสามแถบ 74px: ลากหัวอ่าน · เลือกห้อง · ลากวนซ้ำ — ผู้ใช้ขอให้รวม · ลากช่วงแล้วช่องห้องในแผงตั้งค่าตามช่วงนั้นแทนแถบเลือกห้อง)
ช่วงเก็บใน `loopRange` (tick) ใช้ `scope="range"` ผ่าน `region()` · ปุ่มย้อน/ถัดไปเลื่อนช่วงทีละช่วง

```
.tprow.main    ปุ่มเล่น/หยุด/กลับต้น + นาฬิกา (.clock)
#rowVals       เลือกค่าโน้ต (.valwrap) — เลื่อนแนวนอน ไม่ wrap
#rowLive       ฟัง/วนซ้ำ/เมโทรนอม/ความเร็ว
#rowMore       ของที่ใช้น้อยกว่า — ซ่อนเมื่อ .min
#barHint       คำใบ้ของห้องที่ playhead อยู่
```

## ช่องชื่อแถว (`#labels .r`) — รอบปรับเป้าแตะ

`--labelw` 172px บนจอกว้างกว่า 700px · 128px บนมือถือ (เดิม 132 / 112 ชื่อถูกตัดเหลือ "ไฮแฮ…")
ปุ่ม M/S กว้าง 30px สูงเต็มแถว (มือถือ 26px) · แตะชื่อแถวเฉย ๆ ยังไม่ทำอะไรตามเดิม (กันนิ้วโดนตอนเลื่อนจอ)
มือถือใช้ชื่อย่อจาก `ROW_SHORT` ผ่าน `data-sh` + `::after` ข้อความจริงของแถวยังเป็นชื่อเต็ม
smoke-test ตรวจว่าไม่มีชื่อถูกตัด และวงล้อซูมไม่ทับพื้นที่โน้ต
