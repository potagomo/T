# ผัง UI ของ Drum Pro

อ่านไฟล์นี้ตอนต้องรู้ว่าของชิ้นไหนอยู่ตรงไหนก่อนลงมือแก้
ทุกอย่างในนี้ดึงมาจาก `index.html` จริง ถ้าโครงเปลี่ยน ให้แก้ไฟล์นี้ตามด้วย

## แผงทั้งเจ็ด (`.panel`)

ทุกแผงยกเว้น `pSave` ขึ้นต้นด้วย `hidden` แล้วถูกเปิดเมื่อถึงขั้นตอนที่เกี่ยวข้อง
และ **ทุกแผงถูกซ่อนทั้งหมดเมื่อ `body.locked`**

| id | หน้าที่ | โผล่เมื่อ |
|---|---|---|
| `pGrab` | ดึงเสียงจากไฟล์ที่ถอดรหัสตรง ๆ ไม่ได้ (ต้องเล่นจริงตามเวลา) | เปิดไฟล์ที่ decode ไม่ได้ |
| `pGenre` | เลือกแนวเพลง → กำหนดค่าเริ่มต้นกริดและวิธีตรวจจับ | หลังมีเสียงแล้ว |
| `pGrid` | โครงจังหวะ: BPM, จุดเริ่มห้อง 1, อัตราจังหวะ, สวิง, ซูม, เครื่องมือ | หลังมีกริด |
| `pNote` | แก้โน้ตตัวที่เลือกทีละตัว | เลือกโน้ตด้วยเครื่องมือ select |
| `pSave` | จุดบันทึกในเครื่อง + ไฟล์สำรอง .klong | เห็นตลอด |
| `pCheck` | รายการที่ผิดกฎโน้ต (`#viol`) | หลังตรวจ |
| `pDet` | ค่าละเอียดของการตรวจจับ | เปิดเอง |

## กริด (`#gw`) — หัวใจของโปรแกรม

```
#gw                     กรอบนอก overflow:hidden
 └ #gs                  ตัวเลื่อนแนวนอน overscroll-behavior-x:contain
    └ canvas            วาดทั้งหมดด้วยมือ · position:sticky · touch-action:none
 ├ #labels              ชื่อเสียงกลอง ซ้อนทับบน canvas · pointer-events:none
 │   ├ .h               หัว สูง var(--head) = 46px
 │   ├ .st              แถบบรรทัด 5 เส้น สูง 124px
 │   └ .r × N           แถวละ var(--rowh) = 27px · pointer-events:auto
 │       ├ .sw          สี่เหลี่ยมสีประจำเสียง
 │       ├ .nm          ชื่อ
 │       ├ .so / .mm    solo / mute
 ├ #zwheel              วงล้อซูม ขวามือ · ย่อได้ (.slim)
 ├ #muteWarn            แถบเตือนว่ามีเสียงถูก mute อยู่
 └ #pop                 popup แก้ค่าโน้ต
```

### พิกัดภายใน canvas

* แกนนอน: `X0(t) = LABELW() + (t - S.offset) * S.zoom` — `T0(x)` คือตัวกลับ
* แกนตั้งของบรรทัด 5 เส้น: `py(pos) = STAFF_TOP + (8 - pos) * HG` โดย `HG = 4`
  (`pos` 0 = เส้นล่างสุด, 8 = เส้นบนสุด)
* `STAFF_TOP = HEAD + 46`
* แถวเสียงกลองเริ่มหลังหัว + แถบบรรทัด แต่ละแถวสูง `--rowh`

### บริเวณที่รับการแตะ (ดู `cv.addEventListener("pointerdown")`)

| บริเวณ | ผล |
|---|---|
| `p.head && p.y < 26` | **ลาก playhead** แล้วกดเล่นจะเริ่มจากตรงนั้น |
| `p.head` ส่วนล่าง | เลือกช่วงห้อง (นิ้วในโหมด pan ปล่อยผ่าน) |
| `p.staff` | ไม่ทำอะไร (แถบบรรทัด 5 เส้น) |
| แถวเสียง | วาง/ลบ/เลือก/ปรับน้ำหนัก ตามเครื่องมือที่เลือก |

รับทีละจุดสัมผัสเท่านั้น (`activePid`) เพราะฝ่ามือแตะจอตอนใช้ปากกาเคยทำให้
เกิดโน้ตผิดและมีเสียงกลองดังขึ้นมาเอง

## Transport bar (`#tp`)

`position:fixed` ติดขอบล่างเสมอ **แม้อยู่ในโหมด `body.locked`**
สูงได้ถึง `52dvh` และเลื่อนในตัวเองได้ · ย่อได้ด้วย `#tpToggle` (`.min`)

```
.tprow.main    ปุ่มเล่น/หยุด/กลับต้น + นาฬิกา (.clock)
#rowVals       เลือกค่าโน้ต (.valwrap) — เลื่อนแนวนอน ไม่ wrap
#rowLive       ฟัง/วนซ้ำ/เมโทรนอม/ความเร็ว
#rowMore       ของที่ใช้น้อยกว่า — ซ่อนเมื่อ .min
#barHint       คำใบ้ของห้องที่ playhead อยู่
```

## คลาสที่ใช้ซ้ำได้ — หาให้เจอก่อนสร้างใหม่

| คลาส | ใช้ทำอะไร |
|---|---|
| `.btn` / `.btn.sm` / `.btn.primary` | ปุ่ม · `primary` = ฟ้าทึบ ใช้กับการกระทำหลัก |
| `.seg` | กลุ่มปุ่มสลับแบบติดกัน ใช้ `aria-pressed` |
| `.field` | ป้าย + ช่องกรอก เรียงแนวตั้ง |
| `.bar` | แถวของ `.field` ที่ wrap ได้ |
| `.valwrap` | ปุ่มค่าโน้ตที่มีรูปโน้ตอยู่บน ชื่ออยู่ล่าง |
| `.chk` | checkbox + ป้าย |
| `.hint` | ข้อความอธิบายสีจาง |
| `.stats` | แถวตัวเลขสรุป |
| `.panel` | กล่องเนื้อหาพร้อมหัวข้อ |
| `.srow` | แถวในรายการจุดบันทึก |

## สถานะของ body

| คลาส | ผล |
|---|---|
| `body.locked` | ซ่อน header/.panel/#drop/#prog เหลือแต่กริดกับ `#tp` · `overflow:hidden` |

ทำแบบนี้แทน `position:fixed` โดยตั้งใจ เพราะวิธี fixed เคยทำให้หน้าเด้งไปโชว์หัวเรื่อง

## ตัวแปร CSS ที่ชั้นเว็บแอปเพิ่มให้

`--sat` `--sab` `--sal` `--sar` = `env(safe-area-inset-*)` เผื่อรอยบาก/ขีดโฮมของ iPhone·iPad
ของใหม่ที่ไปชิดขอบจอต้องเผื่อค่าพวกนี้ด้วย ไม่งั้นจะจมใต้ขีดโฮมตอนเปิดจากหน้าโฮม
