# กุญแจเซ็นแอปวิดเจ็ต

Android ยอมให้ติดตั้งรุ่นใหม่ทับรุ่นเก่าได้ก็ต่อเมื่อเซ็นด้วยกุญแจเดียวกัน กุญแจจึงต้องอยู่ใน repo
ให้ GitHub Actions ใช้ซ้ำได้ทุกครั้งที่ build

ข้อแลกเปลี่ยน: repo นี้เป็น public ใครก็สร้างแอปที่เซ็นด้วยกุญแจนี้ได้
แต่จะเอาไปติดตั้งทับในเครื่องคุณได้ก็ต่อเมื่อคุณเองเป็นคนกดติดตั้งไฟล์นั้น
ให้ดาวน์โหลดแอปวิดเจ็ตจาก https://potagomo.github.io/T/widget/kruta-widget.apk เท่านั้น
และแอปนี้ขอสิทธิ์แค่ "อินเทอร์เน็ต" อย่างเดียว ไม่อ่านไฟล์ รูป รายชื่อ หรือข้อมูลอื่นในเครื่อง
