# input/

- `hero.jpg` — ภาพหลัก Lego Messi หันหลัง เสื้อ MESSI 10 ชูนิ้วชี้ฟ้า (1439×1168)
  **ไม่อยู่ใน git** เพราะ repo นี้เป็น public และภาพเป็นผลงานของคนต่อเลโก้
  ถ้าไม่มีไฟล์นี้ ให้ขอเจ้าของงานแนบภาพในแชต แล้วบันทึกเป็น `input/hero.jpg`
  ตรวจว่าเป็นภาพเดียวกัน: `sha1sum input/hero.jpg` ต้องตรงกับ `image_sha1` ใน `hero_rig.json`
  (ถ้าเป็นภาพเดียวกันแต่ขยายความละเอียดมา sha1 จะไม่ตรง — ใช้ได้ แต่ต้องดูผลแยกชั้นอีกครั้ง)
- `hero_rig.json` — โครงหุ่นเชิด: เส้นขอบหัว เสื้อ แขนซ้าย/ขวา จุดหมุน ปลายนิ้ว และวิธีทำเลข 19
