# input/archive — ภาพถ่ายจริงของ Messi บนจอยักษ์ในสนาม

ภาพในโฟลเดอร์นี้ไม่เข้า git (ดู `.gitignore`) — เก็บเฉพาะไฟล์นี้กับ `credits.md`

## ใช้ยังไง
- action `screen` ใน `timeline.json` เช่น
  `{ "do": "screen", "t": 26.1, "dur": 2.8, "src": "2014_golden_ball.jpg", "year": 2014, "focus": [0.5, 0.35] }`
  - `src` ชื่อไฟล์ในโฟลเดอร์นี้ · `year` ใช้เกรดสีให้ "แก่" ตามยุค · `focus` จุดที่ต้องการให้อยู่กลางจอ (สัดส่วน 0–1 ของภาพ)
  - เลือกได้: `zoom` [a, b] (Ken Burns), `w` ความกว้างจอ (0.84), `y` ตำแหน่งกลางจอ (0.25), `aspect` (1.5), `gain`
- **ถ้าไม่มีไฟล์ = ไม่วาดอะไรเลย** คลิปเหมือนเดิมทุกพิกเซล
- ดูตำแหน่งก่อนมีภาพ: ตั้ง `Renderer.placeholders = True` จะเห็นกรอบ "ARCHIVE PHOTO · ปี"
- กติกา: จอกับตัวหนังสือห้ามขึ้นพร้อมกัน (ตัวหนังสือจะทับภาพ)
