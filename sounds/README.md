# เสียงกลองจริง (sounds/)

ชุดเสียงที่อัดจากกลองจริง ใช้แทนเสียงสังเคราะห์เดิมของโปรแกรม
เลือกชุดได้ที่แผงตั้งค่า ส่วน **การฟัง → ชุดเสียงกลอง**

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `klong-sounds.js` | ตัวเล่นเสียง: โหลดชุดที่เลือก เลือกชั้นเสียงตามน้ำหนัก สุ่มไม่ซ้ำ ปิดไฮแฮต แพนซ้ายขวา ปุ่มเลือกชุด |
| `kits.json` | รายชื่อไฟล์ของทุกชุด ชิ้นกลอง ชั้นเสียง และ `playGain` (ความดังของแต่ละชิ้น) |
| `01_rock` … `05_acoustic` | ห้าชุดหลัก ไฟล์ละหนึ่งการตี (MP3) |
| `06_extra_pieces` | ชิ้นเสริม ตอนนี้ใช้ ไรด์เบลล์ ไชน่า สแปลช คาวเบล ให้ทุกชุด |
| `LICENSES.txt` | ที่มาและสัญญาอนุญาตของเสียงทุกชุด |

มาจากชุดเสียงของแอป "กลองนำทาง" (ไฟล์ `klong-namthang-drum-sounds.zip`)

## ต่อเข้ากับโปรแกรมยังไง

`index.html` แตะแค่สองที่ (merge-upstream.py เช็คว่ายังอยู่หลังรวมรุ่นใหม่)
1. `<script src="./sounds/klong-sounds.js">` ใน `<head>`
2. บรรทัดเดียวใน `playVoice()`: ถ้า `KlongSounds.play(...)` คืน `true` ไม่ต้องเล่นเสียงสังเคราะห์

ถ้าคืน `false` (เลือก "สังเคราะห์" · ชุดยังโหลดไม่เสร็จ · ไม่มีไฟล์ของท่านั้น) โปรแกรมเล่นเสียงสังเคราะห์ต่อ ไม่มีวันเงียบ

## เสียงของโปรแกรม → ไฟล์

| เสียงในโปรแกรม | ไฟล์ | หมายเหตุ |
|---|---|---|
| กระเดื่อง สแนร์ ไฮแฮตปิด/เปิด/เท้า ทอม 1-2 ฟลอร์ทอม แครช 1-2 ไรด์ | ชุดที่เลือก | |
| ไรด์เบลล์ ไชน่า สแปลช คาวเบล | ชิ้นเสริม | ชุดหลักไม่มี |
| ริมช็อต | สแนร์ชั้นเน้น +2.5 dB | ไม่มีไฟล์ริมช็อตแยก |
| ครอสสติ๊ก | เสียงสังเคราะห์เดิม | ไม่มีไฟล์ |

## สิ่งที่ต้องรู้ก่อนแก้

* **ไฟล์ MP3 มีช่วงเงียบหัวไฟล์ 7-25 ms หลังถอดรหัส** (แม้ใน Chrome) ตัวเล่นหาจุดเริ่มเสียงจริงให้เอง
  ถ้าลบส่วนนี้ เสียงกลองจะช้ากว่าโน้ตบนกริดและเพลงจริง ชุดทดสอบเช็คว่าเสียงเริ่มไม่เกิน 3 ms จากเวลาที่ตั้ง
* **ความดังของแต่ละชุด (`trim` ใน `KITS`)** เทียบให้ดังพอ ๆ กับเสียงสังเคราะห์เดิม +2 dB
  ผู้ใช้จึงไม่ต้องปรับแถบ "กลอง" ใหม่ ถ้าเพิ่มชุดใหม่ต้องวัดแล้วตั้งค่านี้ด้วย
* **ไฟล์เสียงเก็บในแคชถาวร `drum-samples-v1`** ของ Service Worker (ไม่ถูกล้างตอนอัปเดตโปรแกรม)
  ถ้าเปลี่ยนเนื้อหาไฟล์เสียงเดิม ต้องเปลี่ยนชื่อแคชใน `sw.js` เป็น v2 ไม่งั้นเครื่องผู้ใช้ยังเล่นไฟล์เก่า

* ชุด 1-4 และชิ้นเสริม: **CC0** ใช้ได้ทุกอย่าง ไม่ต้องให้เครดิต
* ชุดอะคูสติก (`05_acoustic`): **Salamander Drumkit by Alexander Holm (CC BY-SA 3.0)**
  ต้องให้เครดิต (แสดงใต้ปุ่มเลือกชุดเมื่อเลือกชุดนี้) ตัวไฟล์เสียงที่แก้แล้วต้องแจกด้วยสัญญาเดียวกัน
  แต่โปรแกรมที่แค่เล่นเสียงนี้ไม่ต้องใช้สัญญานี้
