# ไฟล์ต้นฉบับดิบ — อย่าแก้ไฟล์ในโฟลเดอร์นี้ด้วยมือ

`klong-pro.html` คือไฟล์ที่ผู้พัฒนาส่งมา **ล่าสุด** ในสภาพที่ยังไม่เติมอะไรเลย

มันไม่ได้มีไว้ให้ deploy แต่มีไว้เป็น **จุดอ้างอิงตอนรวมรุ่นใหม่** (merge base)
git ต้องรู้ว่า "รุ่นก่อนหน้าหน้าตาเป็นยังไง" ถึงจะแยกออกว่าอะไรคือของใหม่จากผู้พัฒนา
และอะไรคืองานที่เราแก้ไว้เอง แล้วรวมสองฝั่งเข้าด้วยกันโดยไม่ทับกัน

`tools/merge-upstream.py` เป็นตัวอัปเดตไฟล์นี้ให้เอง หลังรวมรุ่นใหม่สำเร็จ
ถ้าไปแก้เองมันจะเพี้ยนทันที เพราะจุดอ้างอิงไม่ตรงกับความจริงอีกต่อไป
